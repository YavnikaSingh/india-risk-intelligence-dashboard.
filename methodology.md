# Methodology and Limitations

## Purpose
This portfolio prototype organises selected geopolitical risk themes affecting India and provides a structure for monitoring events, sources and possible implications.

## Risk scores
The included scores are illustrative examples from the existing portfolio framework as previously described; they have not been independently recalculated here. Before public use, document the score scale, weights, indicator normalisation, thresholds, missing-data treatment and update schedule. A score is an analytical framework output, not a probability.

## Event tracker
Rows in `data/events.csv` are illustrative monitoring prompts, not verified reports of events on the dates shown. Replace each row with a real, dated event and direct source before describing the tracker as an event database.

## Evidence standards
- Prefer primary and authoritative sources.
- Record event date and date the source was checked.
- Separate fact, attributed claim, analyst judgement and scenario.
- Record uncertainty and conflicting evidence.
- Do not claim real-time monitoring unless updates are performed.

## Limitations
This prototype does not automatically ingest news, validate sources, calculate forecast probabilities or provide operational security alerts.

# India Risk Intelligence — Portfolio Prototype

A Streamlit prototype presenting India-facing geopolitical risk themes, a structured event-tracker interface, and an example intelligence brief.

## Features
- Risk dashboard and chart
- Filterable event tracker
- Featured West Asia–South Asia brief
- Methodology and limitations

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Important data note
Risk scores are illustrative framework values and must be verified against the source workbook and methodology before publication. Event rows are illustrative prompts, not verified event reports. Replace them with sourced, dated records before describing the app as a live monitor.

## Limitations
No automatic news ingestion, real-time alerts, probabilistic forecasting or independent source verification is implemented.
